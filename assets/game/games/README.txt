ARCADIUMX — NETLIFY CLOUD ACCOUNTS EDITION

This is the website folder for manual drag-and-drop deployment to an EXISTING Netlify site. The site URL does not need to change.

Before deploying, complete SETUP-CLOUD-ACCOUNTS.txt and configure cloud-config.js with your Supabase project URL and public key. The website cannot create online accounts until Supabase is configured.

Root must contain index.html, cloud-config.js, cloud-save.js, assets/, game/, and games/. Upload the contents of this folder to the existing Netlify site deploy area, not the ZIP file itself.

Games: Aquasub Go, Jet Rush, FLUXR. The custom crosshair feature is not included.
